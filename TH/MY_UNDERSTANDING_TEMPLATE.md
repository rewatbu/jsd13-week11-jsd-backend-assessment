ตอบแต่ละคำถามด้วยคำพูดของคุณเอง ไม่มีคำถามหลอกล่อ

เป้าหมายไม่ใช่คำตอบที่สมบูรณ์แบบ แต่เป็นคำตอบที่ตรงไปตรงมา เขียนเหมือนกำลังอธิบายให้เพื่อนที่ไม่เคยใช้ Express หรือ React ฟัง Assessment นี้ไม่มีวิดีโอ ดังนั้นเอกสารนี้คือจุดที่ความเข้าใจของคุณจะถูกประเมินจริง ๆ — ให้ทำอย่างตั้งใจ

อย่า copy จาก documentation, comment ในโค้ดของคุณ, หรือ AI output ถ้าไม่แน่ใจเรื่องไหน ให้เขียนเท่าที่คุณเข้าใจ และระบุว่าส่วนไหนยังไม่แน่ใจ

## Backend

**1. HTTP method แต่ละตัวในแอปของคุณหมายถึงอะไร — GET, POST, PUT or PATCH, และ DELETE? ทำไมเราถึงใช้ method ต่างกัน แทนที่จะใช้ POST สำหรับทุกอย่าง?**

*คำตอบของคุณ:*
ในทางเทคนิค HTTP method สามารถทำหน้าที่แทนกันได้แต่ไม่ควรทำ เราควรใช้ method แต่ละตัวตามความหมายที่ถูกออกแบบมา เพื่อให้เกิดความชัดเจนว่า method หรือ API ที่เราทำขึ้นมามีจุดประสงค์อะไร ซึ่งจะทำให้คนที่ทำงานในโปรเจกต์ร่วมกันเข้าใจโครงสร้างของแอป และควรปรับแต่งส่วนอื่นๆ ให้เข้ากันตามวัตถุประสงค์ของ API ตัวนั้น ไม่ใช่ว่าใช้ GET /users แล้วกลายเป็นการลบข้อมูลทั้งหมด

---

**2. `express.json()` คืออะไร และจะเกิดอะไรขึ้นถ้าคุณไม่ใส่มัน?**

*คำตอบของคุณ:*
express.json() คือ middleware ตัวหนึ่งที่ทำหน้าที่ในการแปลงข้อมูล request response ที่ส่งไปมาระหว่าง browser/client และ server ให้อยู่ในรูปแบบที่เข้าใจกันได้ เช่น browser ส่งคำขอไปใน req.body ซึ่งเป็นรูปแบบ JSON แล้ว express.json() ก็จะทำให้ข้อมูลนั้นกลายเป็น object ของ JavaScript เพื่อให้ server สามารถใช้งานได้ ถ้าไม่ใช้มันใน express ก็จะทำให้เกิด error ที่เป็น TypeError เพราะข้อมูลที่ส่งไปให้เซิฟเวอร์ถูกมองเป็น undefined ทำให้เซิฟเวอร์ทำงานต่อไม่ได้

---

**3. `req.body`, `req.params`, และ `req.query` ต่างกันอย่างไร? ยกตัวอย่างจริงจาก API ของคุณสำหรับแต่ละตัว**

*คำตอบของคุณ:*
req.body คือสิ่งที่ถูกส่งไปกับ request body เมื่อใช้ HTTP method POST/PUT/PATCH
req.params คือ url path parameters เช่น id ใน http://localhost:3000/products/2 req.params.id คือ 2 ใน app.put("products/:id", ...)
req.query คือ query string parameters ที่อยู่ใน url ต่อจาก url path เช่น http://localhost:3000/products?productName=soap&price=99 เพื่อใช้ในการค้นหาหรือกรองข้อมูลที่ต้องการ

**6. ทำไม order ของ middleware ใน Express ถึงสำคัญ? จะเกิดอะไรขึ้นถ้า order ผิด?**

*คำตอบของคุณ:*
ลำดับของ middleware มีความสำคัญ เพราะถูกเรียกใช้งานตามลำดับ
หากเรียง order ผิด ก็อาจทำให้เกิดความผิดพลาดได้
เช่นการเรียกใช้ app.use(express.json()) เอาไว้หลังการเรียกใช้ HTTP POST
ก็จะทำให้ req.body ที่ถูกส่งไปยังเซิฟเวอร์ไม่ใช่รูปแบบฟอร์แมตที่เซิฟเวอร์ต้องการ
เพราะ express.json() ถูกเรียกใช้หลังจากที่ข้อมูลถูกส่งออกไปแล้ว
